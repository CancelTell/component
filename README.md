# COMPONENT — справочник комплектующих для ПК

Каталог компьютерных комплектующих с характеристиками, сравнением до 4 моделей и проверкой совместимости.
Свёрстан по макету Figma (430 / 768 / 1024 / 1440).

**Стек:** Next.js 15 (App Router) · React 19 · TypeScript (strict) · чистый CSS на дизайн-токенах · lucide-react · шрифты IBM Plex Sans + IBM Plex Mono через `next/font`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # продакшен-сборка (страницы каталога и моделей генерируются статически)
npm start
npm run typecheck
```

Нужен Node.js 18.18+ (рекомендуется 20+). Для продакшена задайте адрес сайта — от него строятся canonical, sitemap и OG-ссылки:

```bash
NEXT_PUBLIC_SITE_URL=https://example.com npm run build
```

Деплой: Vercel (импорт репозитория, без настроек) или любой Node-хостинг через `npm run build && npm start`.

## Страницы

| Маршрут | Что это | Рендеринг |
|---|---|---|
| `/` | Главная: поиск, категории, возможности | статика |
| `/catalog` | Все категории | статика |
| `/catalog/[category]` | Каталог с фильтрами, сортировкой и панелью сравнения | статика (SSG) |
| `/catalog/[category]/[slug]` | Страница модели: характеристики, совместимость, похожие | статика (SSG) |
| `/compare` | Таблица сравнения, «только различия», лучшее значение жирным | клиент |
| `/compatibility` | Конструктор сборки: готовые сборки, подбор под бюджет, 8 слотов, 7 проверок, цена, «В корзину», «Поделиться» (`?build=cpu:slug,gpu:slug`) | клиент |
| `/cart` | Корзина сборок: цены по магазинам, где дешевле целиком и по частям | клиент, noindex |
| `/search?q=` | Поиск и пустое состояние «Ничего не найдено» | сервер |
| `/about` | О проекте и контакты | статика |

Плюс `sitemap.xml`, `robots.txt`, favicon, 404, JSON-LD `Product` на страницах моделей.

**Интерфейс:** живой градиентный фон в красноватых тонах (`components/layout/AmbientBackground.tsx`, `styles/ambient.css`) и смена темы с круговым раскрытием и лёгким блюром (View Transitions); анимированные мини-демо в блоке «Что можно сделать»; «полёт» модели в сравнение (`lib/fly-to-compare.ts`); страница сравнения с карточками моделей, полосами значений и счётом побед; карточки категорий в виде папок — при наведении «карман» уезжает вниз, а векторная иллюстрация комплектующего поднимается и прорисовывается линиями (`components/ui/ComponentArt.tsx`, `styles/art.css`); в каталоге клик по карточке раскрывает быстрый просмотр прямо под строкой карточек (←/→ — соседние модели, Esc — закрыть); тёмная тема по умолчанию и переключатель на светлую (выбор запоминается, без мигания при загрузке); выезжающая панель у пунктов меню на десктопе (описание категории, быстрый выбор, популярные модели); подсказки в поле поиска прямо при вводе (стрелки ↑↓ и Enter работают с клавиатуры).

## Архитектура

```
src/
  app/                  маршруты App Router, metadata, sitemap, robots
  components/
    layout/             Header (+ мобильное меню), Footer
    home/               Hero, CategoryGrid, Features
    catalog/            CatalogView (фильтры/сортировка), ProductCard, CompareButton, ComparisonBar
    product/            ModelHero, SpecTable, ModelAside
    compare/            CompareView
    compat/             CompatBuilder (+ выбор модели в шторке)
    search/             SearchField, SearchSuggestions
    ui/                 Breadcrumbs, Sheet, Switch, Stat, CategoryIcon
  data/
    types.ts            типы продукта, характеристик, фильтров
    categories.ts       конфигурация категорий: группы характеристик, фильтры, карточки
    products/*.ts       данные моделей
  lib/
    catalog.ts          фильтрация, сортировка, статы, похожие модели
    compatibility.ts    правила совместимости (чистые функции)
    search.ts           поиск по токенам
    format.ts           форматирование значений (ru-RU, единицы, склонения)
    store.ts            хранилище на localStorage + useSyncExternalStore
    compare-store.ts    список сравнения (до 4 моделей в категории)
    build-store.ts      сборка для проверки совместимости
  styles/               tokens.css (палитры тёмной и светлой темы, радиусы, шрифты) и стили по разделам
```

**Наличие в магазинах:** `src/data/offers.ts` читает `data/offers.json` (заполняется автоматически, см. «Данные: каталог и цены обновляются сами»). Блок выводится на странице модели, в быстром просмотре, в конструкторе и корзине.

**Как добавить модель:** обычно ничего делать не нужно — модели из фидов магазинов добавляются сами. Вручную: объект в `src/data/products/*.ts` и `npm run data:catalog` (или дождаться ночного запуска).

**Как добавить характеристику или фильтр:** опишите её в `src/data/categories.ts` (`groups` — для таблицы и сравнения, `filters` — для фильтров, `cardSpecs`/`keySpecs` — что показывать в карточке и в шапке модели).

**Правила совместимости** (`src/lib/compatibility.ts`): сокет процессора и платы; тип памяти у процессора и у платы; мощность БП (TDP процессора + видеокарты + 75 Вт, запас 30 %, не ниже рекомендации видеокарты); корпус — форм-фактор платы и длина видеокарты.

Состояние сравнения и сборки хранится в `localStorage`, фильтры каталога — в URL (ссылкой с фильтрами можно поделиться).

## Инструкция по сборке (`/guide`)

9 шагов с векторными анимациями: руки показывают действие, список справа подсвечивает текущий шаг, клик по пункту перематывает сцену.

- `src/components/guide/scenes-1.tsx`, `scenes-2.tsx` — сцены: SVG + дорожки анимации (`tracks`) + фазы с текстом.
- `src/components/guide/timeline.ts` — `tr()` превращает короткую запись кадров в keyframes Web Animations API; `show`, `draw`, `ring` — частые шаблоны.
- Элемент участвует в анимации, если у него `data-t="имяДорожки"`. Все дорожки шага делят одну длительность, поэтому перемотка и пауза общие.
- `GuideView.tsx` — плеер: пауза вне экрана, `?step=cpu`, отметки «сделано» (localStorage), клавиши ← →, пробел.
- Новая сцена: объект `GuideStep` в `scenes-*.tsx` и строка в `steps.ts`.

## Готовые сборки и подбор

- `src/data/presets.ts` — готовые сборки (главная и конструктор). Добавить свою — новый объект со слагами моделей.
- `src/lib/auto-build.ts` — подбор под бюджет: перебирает пары процессор + видеокарта, остальное берёт самым дешёвым совместимым, побеждает пара, где больше вложено в видеокарту.
- `src/lib/share.ts` — ссылка на сборку и её чтение.

## Данные: каталог и цены обновляются сами

```
Фиды магазинов (YML) ─┐                         ┌─ data/catalog.json      ← модели и характеристики
Open Icecat (JSON) ───┼─ scripts/pipeline ─────┼─ data/offers.json       ← цены по магазинам
data/overrides.json ──┘   (GitHub Actions)      ├─ data/price-history.json
                                                └─ data/report.md        ← что не удалось добавить
            коммит в репозиторий → Vercel пересобирает сайт
```

- **Каталог** (`npm run data:catalog`, раз в сутки):
  - процессоры и видеокарты (чипы) — из таблиц английской Википедии (`scripts/pipeline/wikipedia.ts`); страницы — в `data/import-config.json`;
  - платы, память, SSD, блоки питания, кулеры, корпуса — из общего списка Open Icecat (`icecat-index.ts`), по `perCategory` новых карточек за запуск на категорию;
  - фиды магазинов показывают, какие модели продаются, и дополняют характеристики. Модель публикуется, только если известны поля для проверки совместимости (`REQUIRED` в `normalize.ts`), иначе попадает в `data/report.md`.
- **Цены** (`npm run data:prices`, каждые 4 часа): предложения привязываются к моделям по штрихкоду, коду производителя или названию; видеокарты — по чипу (все версии RTX 4060 → одна модель, цена «от»). Сохраняется самое дешёвое предложение в наличии на магазин и точка истории цен за день.
- **Ручные правки**: `data/overrides.json` — исправить характеристику, добавить код модели, скрыть модель. Главнее автоматики.
- **Ручные модели**: `src/data/products/*.ts` — всегда попадают в каталог.
- **Проверка без ключей**: `npm run data:test` — прогон на тестовых фидах из `scripts/pipeline/fixtures`, результат в `.cache/test`.
- **Демо-цены**: пока `data/offers.json` пуст, сайт показывает демо-цены с пометкой; первая настоящая выгрузка выключает их сама.

Переменные окружения (GitHub → Settings → Secrets and variables → Actions):

| Секрет | Откуда |
|---|---|
| `ICECAT_USERNAME` | логин Open Icecat (бесплатная регистрация) |
| `ICECAT_PASSWORD` | пароль Open Icecat — нужен для общего списка товаров |
| `ICECAT_API_TOKEN` | необязательно, токен из кабинета Icecat |
| `FEED_DNS`, `FEED_OZON`, `FEED_CITILINK`, `FEED_MVIDEO` | ссылки на товарные фиды (YML) из партнёрской сети |

Что нашлось в Википедии и Icecat (таблицы, колонки, категории) — в `data/sources-report.md`.

Новые характеристики учатся так: в `data/report.md` есть список нераспознанных параметров — для нужных добавьте правило в `RULES` (`scripts/pipeline/normalize.ts`).

## Данные

Характеристики реальных моделей взяты из спецификаций производителей и носят справочный характер. Длина видеокарт указана для эталонных версий — у партнёрских карт она обычно больше. Изображения пока заменены иконками-заглушками, как в макете.

## Превью без Next.js

Папка `preview/` — служебная: собирает те же страницы в один HTML-файл с хеш-роутингом (через esbuild и заглушки для `next/*`), чтобы показать дизайн без сервера. В приложение она не входит и может быть удалена.
